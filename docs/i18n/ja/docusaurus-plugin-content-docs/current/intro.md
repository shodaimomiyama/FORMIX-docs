# FORMIX 入門

**FORMIX**（Deterministic Threshold Proxy Re-Encryption System）は、Arweave上に保存された暗号化データのための分散型アクセス制御システムです。元の暗号鍵を公開することなく、安全でパーミッションレスなデータ共有を可能にします。

## FORMIXとは？

FORMIXは**閾値プロキシ再暗号化（TPRE）**技術を実装しており、データ所有者が分散プロキシノードを通じて他のユーザーに復号権限を委任できます。これにより、以下の特性を持つトラストレスなシステムを構築します：

- **単一障害点なし** - 復号には複数のプロキシノードの協力が必要
- **所有者が制御を保持** - アクセス権はいつでも付与・取り消し可能
- **エンドツーエンド暗号化** - データはプロセス全体を通じて暗号化されたまま

## 主な特徴

### 閾値プロキシ再暗号化
暗号技術を使用して、再暗号化機能を複数の独立したノードに分割します。閾値数のノードがデータを再暗号化するために協力する必要があり、ビザンチン障害耐性を提供します。

### 分散アーキテクチャ
永続ストレージにArweave、コンピューティングにAO Networkを使用し、中央の制御点や障害点を排除します。

### マルチロールWasmアクター
3つの異なるプロセスタイプ（Owner、Holder、Requester）がAO上のWebAssemblyモジュールとして動作し、アクセス制御ワークフローにおいてそれぞれ特定の責任を担います。

## 技術スタック

| コンポーネント | 技術 | 目的 |
|-----------|------------|---------|
| ストレージ | Arweave | 永続的な分散データストレージ |
| コンピューティング | AO Network | 分散プロセス実行 |
| 暗号化 | Umbral TPRE (Rust/Wasm) | 閾値プロキシ再暗号化 |
| スマートコントラクト | AO Network (Rust → WASM) | 再暗号化鍵の調整 |

## 現在のステータス

:::info 現在のステータス（2026年6月）
FORMIXは現在、**ローカルモード**（インメモリのMock AOバックエンド）で完全に動作します — これが現時点でサポートされているパスです。
**HyperBEAM** 経由のAO Networkへの本番接続（`hyperbeam` フィーチャーフラグ: RFC-9421 HTTPメッセージ署名、TABMエンコーディング）は**実験的**であり、エンドツーエンド統合は進行中です。
フィーチャーフラグの詳細は [FormixClient API](/docs/api/formix-client) を参照してください。
:::

### 背景

FORMIXのコントラクトレイヤーは当初、AO向けの実験的なCosmWasmベースのランタイムである **cwao** を使用して構築されていました。AO Networkはcwaoとの互換性を失う根本的なプロトコル変更を経て、AOエコシステムの焦点は「Verifiable Internet」OSである **HyperBEAM** へとシフトしました。FORMIXもエコシステムに合わせて方針を転換しています：コントラクトは現在、HyperBEAMをターゲットとするプレーンな **Rust → WASM** モジュールとなり、クライアントには実験的な **HyperBEAMトランスポート**（`hyperbeam` フィーチャー: RFC-9421 `rsa-pss-sha512` HTTPメッセージ署名、TABMマルチパートエンコーディング）が追加されました。

### 開発者にとっての意味

| モード | ステータス | 説明 |
|------|--------|-------------|
| **ローカルモード**（デフォルト） | 利用可能 | 完全なTPREワークフローが、ネットワーク依存なしにローカルで動作します。暗号操作（Umbral PRE、Shamir SSS、AES-GCM）とコントラクトロジックは、インメモリのMock AOバックエンドに対してネイティブに実行されます。 |
| **本番モード**（`hyperbeam` フィーチャー） | 実験的 | HyperBEAMクライアント（HTTP署名、TABMエンコーディング）は実装済みで、AO Networkとのエンドツーエンド統合は進行中です。実ワークロードへの使用はまだ推奨されません。 |

コア暗号ライブラリとプロトコルロジックは**完全に機能し安定しています** — 進行中の作業はインフラレイヤー（ストレージおよびコンピューティングバックエンド）にのみ影響します。
